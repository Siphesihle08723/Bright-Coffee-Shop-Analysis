# ☕ Coffee Shop Sales Analysis

## Project Overview

This project analyzes coffee shop sales data to identify sales trends, customer purchasing patterns, and product performance. The analysis was completed using SQL for data cleaning and analysis, and Power BI and google looker studio for interactive dashboard creation.

The goal is to transform raw transaction data into meaningful insights that can help improve business decisions.

## Objectives

* Clean and prepare the sales dataset.
* Calculate total sales revenue.
* Analyze sales by product category and product type.
* Identify peak sales hours.
* Compare weekday and weekend sales.
* Analyze monthly sales performance.
* Evaluate store performance by location.
* Create an interactive dashboard to visualize key business metrics.

## Dataset

The dataset contains transaction-level information, including:

* Transaction ID
* Transaction Date
* Transaction Time
* Store Location
* Product Category
* Product Type
* Product Detail
* Unit Price
* Quantity Sold

## Tools Used

* Databricks – Data cleaning and transformation.
* SQL – Data manipulation and calculations.
* Power BI – Dashboard development.
* Google Looker - Dashbourd Development.
* GitHub – Version control and project portfolio.

## Data Cleaning

The following data preparation steps were performed:

* Converted data types where necessary.
* Corrected unit price values.
* Created **Total Amount** (`Unit Price × Transaction Quantity`).
* Extracted Month Name, Day Name, and Transaction Hour.
* Created **Day Type** (Weekday or Weekend).
  

## Dashboard Features

The Power BI dashboard includes:

* Total Revenue
* Total Transactions
* Total Quantity Sold
* Average Sales
* Revenue by Product Category
* Revenue by Product Type
* Revenue by Store Location
* Sales by Month
* Sales by Day Type
* Sales by Transaction Hour

## Key Insights

* Coffee products generated the highest sales revenue.
* Morning hours recorded the highest number of transactions.
* Weekend sales were generally stronger than weekday sales.
* Sales performance varied across store locations.
* Revenue trends changed across different months, highlighting seasonal demand.

## Recommendations

* Increase staff during peak morning hours.
* Maintain sufficient inventory for best-selling products.
* Introduce promotions during slower sales periods.
* Expand popular product offerings.
* Monitor store performance regularly to improve operational efficiency.
